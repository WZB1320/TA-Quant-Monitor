## 四、API 契约

### GET /api/dashboard/snapshot
```jsonc
{
  "snapshot": { ...与现 demo data/dashboard.json 完全相同的 schema... },
  "freshness": {
    "data_date": "2026-09-24",        // 快照数据日期
    "latest_trade_date": "2026-09-28",// 探针探测的最新交易日
    "stale_trade_days": 2,            // 距今 N 个交易日
    "is_fresh": false                 // data_date == latest_trade_date
  },
  "generated_at": "2026-09-28T11:20:00"
}
```
无快照时 `snapshot=null`，前端进入「首次生成」空态。

### POST /api/dashboard/refresh
- `BackgroundTasks` 异步执行 builder；**进程内互斥锁**：已有生成在跑时返回 409 + 当前任务信息（防双击双跑）。
- 生成在**独立线程**执行，写快照用**临时文件 + 原子替换**，失败不触碰旧快照。

### GET /api/dashboard/status
```jsonc
{ "state": "idle | running | success | failed",
  "stage": "fetch_index | fetch_stocks | backtest | signals | build",
  "progress": 0-100, "error": null, "started_at": ..., "finished_at": ... }
```

## 五、前端页面设计（移植 demo，不重新设计）

demo 的设计系统（深蓝黑 + 琥珀金、等宽 tabular-nums、涨红 #F6465D / 跌绿 #0ECB81、色条/进度条/chip）**整体平移**为页面容器内的 CSS 作用域样式（`.dash-scope` 前缀，避免污染 antd 全局主题）。差异点：

| demo 现状 | React 版处置 |
|---|---|
| 手绘 SVG 净值双线 | **echarts-for-react**：面积渐变双线 + KPI 卡沿用（项目已有同款图在 Backtest 页可参照） |
| 20 日 sparkline（SVG） | 保留手绘 SVG（几十个点不值得上 echarts 实例） |
| 手写 JS 字符串拼行 | JSX 组件化：`SignalTable` / `IndexBand` / `PositionPanel` / `NavPanel` 四个子组件 |
| 无交互 | 只读不变；唯一新增：**「重新生成」按钮** + 生成中进度条（需求冻结的"复用快照秒开"要求手动重跑入口） |
| 四态 | 首次无快照 / 新鲜秒开 / 旧数据显示旧值+非最新徽章 / 生成失败显示错误+保留旧值 |
